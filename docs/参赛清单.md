# 参赛清单

时间均为北京时间。

## 开工前

- [ ] 在 11 月 27 日 23:59 前确认三人已报名且在同一队。每人限一队，每队限交一款作品。
- [ ] 摘录正式题面并附官方出处。确定一句话玩法和第一版范围，选定开源引擎、开源框架或自行编码方案，再初始化工程。
- [ ] 把赛前已有的代码、工具和素材填入[素材记录](../compliance/素材记录.md)。

## 开发中

- [ ] 在本届开发期内完成围绕题面的核心玩法与主要内容。做好 ASCII 字符辨识、基本引导和操作反馈。
- [ ] 导出 Windows 测试包，在另一台电脑上从启动玩到结束并正常退出，记录问题。修复后验证最终包支持 Windows 10/11。
- [ ] 在[素材记录](../compliance/素材记录.md)登记作者、来源、许可和用途。
- [ ] 在[AI 使用记录](../compliance/AI使用记录.md)登记工具、用途、生成内容和人工修改。
- [ ] 留存截图、录屏和改动说明。据此公开发布至少 3 篇不同的日志，可分别写初版玩法、一次规则调整、试玩后的修改，保存每篇链接。

## 交稿与互评

- [ ] 准备 AtomGit 仓库链接、最终 commit ID、对应的 Windows 发行包和[启动说明](../release/run-guide.md)。私有仓库须向指定工作人员开放审核权限。
- [ ] 按官方模板完成《AI 使用与素材声明》，放入最终提交的仓库。
- [ ] 准备游戏名称、简介和封面，将不超过 5 分钟的演示视频发布到 B 站，添加「2026 开源游戏开发大赛」活动标签，保存链接。
- [ ] **12 月 5 日队内交稿。** 核对发行包、视频和三篇日志的链接，在官网「个人中心 → 作品提交」提交并确认成功。官方窗口为 **11 月 28 日 00:00 至 12 月 6 日 23:59**。
- [ ] **12 月 7 日至 12 月 20 日 23:59**，按官网要求完成规定互评，保留评奖资格。

[比赛官网与规则](https://2026gamejam.osgame.org/)
